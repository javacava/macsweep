How to free up space from Xcode

On a developer Mac, Xcode quietly becomes one of the biggest things on the disk. Here is every place it stores data, what is safe to delete, and the exact commands — tested on Xcode 26 and macOS 27.

Updated November 21, 2026 · 9 min read · Works with Xcode 15 and later

1. DerivedData

DerivedData holds intermediate build files and indexes for every project you have opened. It is completely safe to delete; Xcode recreates it, and the only cost is a longer first build.

# everything
rm -rf ~/Library/Developer/Xcode/DerivedData/*

# or one project: find its folder first
ls ~/Library/Developer/Xcode/DerivedData

Quit Xcode first. You can also open Xcode → Settings → Locations and click the arrow next to the DerivedData path to see it in Finder.

2. Simulators you do not use

Each simulator keeps its own copy of installed apps and their data. Simulators for runtimes you no longer have cannot even start. Delete those first:

xcrun simctl delete unavailable

To see every simulator and remove a specific one:

xcrun simctl list devices
xcrun simctl delete <UDID>

3. Old simulator runtimes

Runtimes are the biggest single items — each iOS runtime is several gigabytes. List what is installed:

xcrun simctl runtime list

Preview the runtimes you have not used in six months, then delete them:

xcrun simctl runtime delete --notUsedSinceDays 180 --dry-run
xcrun simctl runtime delete --notUsedSinceDays 180

Or remove one by its identifier from the list: xcrun simctl runtime delete <identifier>. You can download any runtime again in Xcode → Settings → Components.

4. iOS DeviceSupport

Every time you connect a device running a new iOS version, Xcode copies its symbols into ~/Library/Developer/Xcode/iOS DeviceSupport (and watchOS/tvOS equivalents). Folders for versions none of your devices run any more can go.

5. Archives — keep the ones you shipped

Archives include the dSYM files you need to symbolicate crash reports for released builds. Delete old archives only for builds that are no longer in users' hands, or after you have uploaded the dSYMs elsewhere.

6. The Metal toolchain

Recent Xcode versions download the Metal toolchain as a separate component. If you do not compile Metal shaders, check whether it is installed and remove it:

xcodebuild -showComponent metaltoolchain
xcodebuild -deleteComponent metaltoolchain

7. Everything else around Xcode

A developer Mac usually has more: node_modules folders, Docker images and build cache, npm/pnpm/Yarn/pip/Cargo/Gradle/CocoaPods caches, Android emulators, and local AI models. These are often as large as Xcode itself.

FAQ

Is it safe to delete Xcode DerivedData?

Yes. It holds build products and indexes that Xcode recreates. The only cost is a longer first build and re-indexing.

How do I delete unavailable iOS simulators?

Run xcrun simctl delete unavailable. It removes simulators whose runtime is no longer supported by the installed Xcode.

How do I delete old simulator runtimes?

List them with xcrun simctl runtime list, then delete one with xcrun simctl runtime delete <identifier>, or preview unused ones with xcrun simctl runtime delete --notUsedSinceDays 180 --dry-run.
