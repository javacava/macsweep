Supported tools

What MyOpenCleaner knows how to clean

AI models and coding agents, Xcode and package managers, language versions, project builds, chat app caches and macOS itself. This list is generated from the app's own rules, so it matches what the app does.

  • Safe to removeRebuilt or downloaded again when needed, or never needed at all. Caches, logs, build files.
  • Check firstMay hold your own work or history, or cannot be brought back as it was. Never selected for you.
  • KeptShown so you know where the space went, never removed: the version you use, a virtual machine's disk.

Ask your AI agent what to clean

MyOpenCleaner includes a read-only MCP server. Claude Code, Claude Desktop, Codex or Cursor can read the scan and suggest a cleanup; nothing is removed until you do it yourself.

claude mcp add myopencleaner -- /Applications/MyOpenCleaner.app/Contents/MacOS/MyOpenCleaner --mcp
